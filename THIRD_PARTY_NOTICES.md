# Sparkle

In-app updates use [Sparkle](https://github.com/sparkle-project/Sparkle), an open-source
software update framework for macOS. Its license and bundled third-party notices
are included in [Resources/Sparkle-LICENSE](Resources/Sparkle-LICENSE) and copied
into the application's Resources directory.

# idb

The CoreSimulator display discovery, Indigo single-touch envelope, DTUHID wire schema,
and Purple orientation message are adapted from or informed by facebook/idb:
https://github.com/facebook/idb

No idb binary, Python runtime, companion server, or network service is required.
